# Gc20

Cyberdeck-Umbau eines Casio-Taschenrechnergehäuses (fx-CG20/fx-CG50) mit
einem Raspberry Pi Zero 2 W – inklusive rückseitiger Kamera, Original-Menü-
Navigation, Galerie, Dokumentenbrowser und Claude-Anbindung neben der
originalen Taschenrechner-Funktion.

Siehe [PROJEKTPLAN.md](PROJEKTPLAN.md) für Zieldefinition, Stückliste,
Tastatur-/Display-/Kamera-Optionen, das Bedienkonzept, die geplanten Apps
und den Bauablauf.
